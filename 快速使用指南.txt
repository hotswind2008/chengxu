===============================================
    三门问题游戏 - 快速使用指南
===============================================

📁 核心文件
-----------
✅ monty_hall_windows.py     - 游戏源码（跨平台优化版）
✅ 一键打包.bat               - Windows 打包脚本
✅ 一键打包.sh                - macOS 打包脚本
✅ 打包说明README.md          - 详细说明文档

📦 已打包文件（macOS）
---------------------
✅ dist/三门问题游戏          - macOS 可执行文件（19MB）


===============================================
快速开始
===============================================

方式1：直接运行源码
------------------
python3 monty_hall_windows.py

方式2：运行打包后的程序（macOS）
--------------------------------
./dist/三门问题游戏

方式3：打包 Windows EXE（需在 Windows 上运行）
---------------------------------------------
1. 将所有文件拷贝到 Windows 电脑
2. 双击运行 "一键打包.bat"
3. 在 dist 文件夹找到 "三门问题游戏.exe"


===============================================
重要说明
===============================================

✨ 跨平台兼容性
--------------
程序会自动识别系统并调整：
- Windows: 使用 Segoe UI Emoji
- macOS: 使用 Apple Color Emoji
- emoji 样式会根据系统不同而不同（正常现象）

🎮 游戏说明
-----------
1. 选择一扇门
2. 主持人打开一扇有山羊的门
3. 选择坚持或换门
4. 观察统计数据，验证换门策略的优势！

⚠️ 注意事项
-----------
- Windows EXE 必须在 Windows 上打包
- macOS APP 已经打包完成
- emoji 在不同系统显示不同是正常的
- 首次启动可能需要几秒钟
